### Ход работы:

#### Задача 1. Настройка Alembic и создание таблиц
**Что нужно сделать:** Настроить миграции и создать первые таблицы в PostgreSQL.
**Для чего это нужно:** Без таблиц база данных пустая, и сохранять пользователей некуда.
**Шаги выполнения:**
1. В терминале (в папке `backend`) выполни: `alembic init alembic`.
2. Открой `backend/alembic/env.py`. Замени `target_metadata = None` на:
   `from app.db.base import Base`
   `import app.db.models`
   `target_metadata = Base.metadata`
3. В `env.py` настрой подключение через `settings.DATABASE_URL`.
4. Открой `backend/app/db/models.py`.
5. Создай класс `User` (id, email, hashed_password, is_active, created_at).
6. Создай класс `Stamp` (id, name, price, country, year, url).
7. Выполни миграцию: `alembic revision --autogenerate -m "create users and stamps tables"`.
8. Примени: `alembic upgrade head`. Проверь в DBeaver.

#### Задача 2. Написание утилит безопасности (`security.py`)
**Что нужно сделать:** Написать функции для шифрования паролей и выдачи токенов.
**Для чего это нужно:** Чтобы пользователи могли безопасно логиниться.
**Шаги выполнения:**
1. Открой `backend/app/core/security.py`.
2. Добавь функцию `get_password_hash(password)` (используй `passlib` и `bcrypt`).
3. Добавь функцию `verify_password(plain, hashed)`.
4. Добавь функцию `create_access_token(subject)` (используй `PyJWT`).

#### Задача 3. Создание Pydantic-схем
**Что нужно сделать:** Описать схемы для валидации данных.
**Для чего это нужно:** FastAPI должен проверять, что фронтенд присылает правильные данные.
**Шаги выполнения:**
1. Открой `backend/app/db/schemas.py`.
2. Создай `UserCreate`, `UserResponse` (с `ConfigDict(from_attributes=True)`).
3. Создай `StampResponse` (id, name, price, country, year, url).

#### Задача 4. Написание эндпоинтов `/register` и `/login`
**Что нужно сделать:** Создать API для входа и регистрации.
**Для чего это нужно:** Это критически важно для Татьяны, чтобы оживить её фронтенд.
**Шаги выполнения:**
1. Открой `backend/app/api/v1/auth.py`.
2. Напиши `@router.post("/register")`: проверь email, захешируй пароль, сохрани юзера.
3. Напиши `@router.post("/login")`: проверь email и пароль, верни `access_token`.

#### Задача 5. Изучение структуры txt-файлов с марками
**Что нужно сделать:** Понять, как хранятся данные в файлах Игоря.
**Для чего это нужно:** Чтобы написать правильный парсер.
**Шаги выполнения:**
1. Открой файл `rus_496.txt`. Ты увидишь строки: «Порядковый номер...», «Ссылка...», «Цена...».
2. Определи, по каким символам (двоеточие, перенос строки) можно разделить текст.

#### Задача 6. Написание Python-скрипта-парсера
**Что нужно сделать:** Написать функцию, которая превращает текст в словарь Python.
**Для чего это нужно:** Для автоматического чтения файлов.
**Шаги выполнения:**
1. Создай файл `backend/app/utils/parser.py`.
2. Напиши функцию `parse_stamp_file(file_path: str) -> dict`.
3. Используй `open()` и `readlines()`, раздели строки и собери в словарь `{"name": ..., "price": ..., "url": ...}`.

#### Задача 7. Написание скрипта массовой вставки (Bulk Insert)
**Что нужно сделать:** Залить 600 марок в базу.
**Для чего это нужно:** Чтобы мгновенно наполнить БД.
**Шаги выполнения:**
1. Создай файл `backend/app/utils/seed_db.py`.
2. Пройдись циклом по папкам `rusMarki` и `EnglMarki`, вызывая функцию из Задачи 6.
3. Используй `db.bulk_save_objects([Stamp(**data) for data in stamps])`.
4. Сделай `db.commit()`.

#### Задача 8. Написание эндпоинтов `GET /stamps` и `GET /stamps/{id}`
**Что нужно сделать:** Создать API для получения марок.
**Для чего это нужно:** Чтобы Татьяна могла вывести карточки на фронте.
**Шаги выполнения:**
1. Открой `backend/app/api/v1/stamps.py`.
2. Напиши `@router.get("/")` (верни `db.query(Stamp).all()`).
3. Напиши `@router.get("/{id}")` (найди марку по ID или верни 404).

#### Задача 9. Написание `pytest` тестов
**Что нужно сделать:** Проверить, что сервер и авторизация работают.
**Для чего это нужно:** Для надежности.
**Шаги выполнения:**
1. Открой `backend/tests/test_auth.py`.
2. Добавь тест на `/health` (статус 200).
3. Добавь тест на `/register` (создание пользователя).
4. Запусти `pytest`.
