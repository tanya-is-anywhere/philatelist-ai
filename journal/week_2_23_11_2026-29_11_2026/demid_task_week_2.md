### Ход работы:

#### Задача 1. Слияние ветки `backend` и запуск миграций
**Что нужно сделать:** Забрать код Виктории и применить миграции.
**Для чего это нужно:** Чтобы в базе появились таблицы для пользователей.
**Шаги выполнения:**
1. Переключись на ветку `backend`: `git checkout backend`.
2. Стяни изменения: `git pull origin backend`.
3. Запусти миграции: `alembic upgrade head`.

#### Задача 2. Проверка таблиц в DBeaver
**Что нужно сделать:** Убедиться, что таблицы создались.
**Шаги выполнения:**
1. Открой DBeaver, обнови список таблиц.
2. Проверь, что появились `users` и `refresh_sessions`.
3. Сделай скриншот.

#### Задача 3. Тестирование эндпоинтов `/register` и `/login`
**Что нужно сделать:** Проверить, что код Виктории работает.
**Шаги выполнения:**
1. Запусти бэкенд: `uvicorn app.main:app --reload`.
2. Открой `http://localhost:8000/docs`.
3. Выполни запрос на регистрацию и вход. Проверь, что приходит `access_token`.
4. Сделай скриншоты.

#### Задача 4. Добавление модели `Stamp` и миграция
**Что нужно сделать:** Создать таблицу для марок (если Виктория её не сделала).
**Для чего это нужно:** Чтобы было куда заливать 600 марок.
**Шаги выполнения:**
1. Открой `backend/app/db/models.py`.
2. Создай класс `Stamp` (id, name, price, country, year, url).
3. Сделай миграцию: `alembic revision --autogenerate -m "create stamps table"`.
4. Примени: `alembic upgrade head`.

#### Задача 5. Изучение структуры txt-файлов с марками
**Что нужно сделать:** Понять, как хранятся данные в файлах Игоря.
**Шаги выполнения:**
1. Открой файл `rus_496.txt`. Ты увидишь строки: «Порядковый номер...», «Ссылка...», «Цена...».
2. Определи, по каким символам (двоеточие, перенос строки) можно разделить текст.

#### Задача 6. Написание Python-скрипта-парсера
**Что нужно сделать:** Написать функцию, которая превращает текст в словарь Python.
**Шаги выполнения:**
1. Создай файл `backend/app/utils/parser.py`.
2. Напиши функцию `parse_stamp_file(file_path: str) -> dict`.
3. Используй `open()` и `readlines()`, раздели строки и собери в словарь `{"name": ..., "price": ..., "url": ...}`.

#### Задача 7. Написание скрипта массовой вставки (Bulk Insert)
**Что нужно сделать:** Залить 600 марок в базу.
**Шаги выполнения:**
1. Создай файл `backend/app/utils/seed_db.py`.
2. Пройдись циклом по папкам `rusMarki` и `EnglMarki`, вызывая функцию из Задачи 6.
3. Используй `db.bulk_save_objects([Stamp(**data) for data in stamps])`.
4. Сделай `db.commit()`.

#### Задача 8. Написание эндпоинтов `GET /stamps` и `GET /stamps/{id}`
**Что нужно сделать:** Создать API для получения марок.
**Для чего это нужно:** Чтобы Татьяна могла вывести карточки на фронте.
**Шаги выполнения:**
1. Открой `backend/app/api/v1/stamps.py`.
2. Напиши `@router.get("/")` (верни `db.query(Stamp).all()`).
3. Напиши `@router.get("/{id}")` (найди марку по ID или верни 404).

#### Задача 9. Написание `pytest` тестов
**Что нужно сделать:** Проверить, что сервер и авторизация работают.
**Шаги выполнения:**
1. Открой `backend/tests/test_auth.py`.
2. Добавь тест на `/health` (статус 200).
3. Добавь тест на `/register` (создание пользователя).
4. Запусти `pytest`.

#### Задача 10. Проверка интеграции и отправка PR
**Что нужно сделать:** Связаться с Татьяной и запушить код.
**Шаги выполнения:**
1. Напиши Татьяне, что эндпоинты `/login`, `/register` и `/stamps` готовы.
2. Попроси её заменить моки на реальные запросы.
3. Сделай коммит и запушь в ветку `backend`. Создай Pull Request.
