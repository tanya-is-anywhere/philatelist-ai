### Ход работы:

#### Задача 1. Создание эндпоинта `POST /recognize` (прием фото)
**Что нужно сделать:** Создать API-метод, который принимает изображение от пользователя.
**Для чего это нужно:** Это точка входа для главной фичи нашего приложения.
**Шаги выполнения:**
1. Открой `backend/app/api/v1/recognize.py`.
2. Создай `@router.post("/")`.
3. В параметрах укажи `file: UploadFile = File(...)`.
4. Внутри функции сохрани файл во временную папку или сразу передай его в ИИ-модуль.

#### Задача 2. Написание сервиса для вызова ИИ-модуля
**Что нужно сделать:** Написать код, который вызывает функцию `detect_stamps` из папки `app/ai`.
**Для чего это нужно:** Чтобы разделить логику API и логику работы нейросети.
**Шаги выполнения:**
1. Создай файл `backend/app/services/ai_service.py`.
2. Напиши функцию `async def process_image(image_path: str)`.
3. Внутри функции импортируй `from app.ai.detector import detect_stamps`.
4. Вызови функцию и получи список координат (bbox).

#### Задача 3. Возврат JSON с координатами марок на фронтенд
**Что нужно сделать:** Сформировать ответ для Татьяны.
**Для чего это нужно:** Чтобы фронтенд мог отрисовать рамки поверх фото.
**Шаги выполнения:**
1. В `recognize.py` возьми результат из `ai_service.py`.
2. Сформируй JSON вида `{"stamps": [{"bbox": [x1, y1, x2, y2], "confidence": 0.95}]}`.
3. Верни его через FastAPI.

#### Задача 4. Создание модели `Collection` (связь пользователя и марки)
**Что нужно сделать:** Описать таблицу, где будет храниться коллекция каждого пользователя.
**Для чего это нужно:** Чтобы пользователь мог сохранять понравившиеся марки.
**Шаги выполнения:**
1. Открой `backend/app/db/models.py`.
2. Создай класс `Collection`: поля `id` (UUID), `user_id` (ForeignKey на User), `stamp_id` (ForeignKey на Stamp), `added_at` (DateTime).
3. Сделай миграцию: `alembic revision --autogenerate -m "create collection table"`.
4. Примени: `alembic upgrade head`.

#### Задача 5. Написание эндпоинта `POST /collection`
**Что нужно сделать:** Создать API-метод для добавления марки в коллекцию.
**Для чего это нужно:** Для кнопки «Сохранить в коллекцию» на фронтенде.
**Шаги выполнения:**
1. Открой `backend/app/api/v1/stamps.py` (или создай `collection.py`).
2. Создай `@router.post("/collection")`.
3. Прими `stamp_id` и `user_id` (из токена).
4. Сохрани запись в БД.

#### Задача 6. Написание эндпоинта `GET /collection`
**Что нужно сделать:** API для получения всех сохраненных марок пользователя.
**Для чего это нужно:** Для страницы «Моя коллекция».
**Шаги выполнения:**
1. Создай `@router.get("/collection")`.
2. Сделай запрос к БД: `db.query(Collection).filter(Collection.user_id == current_user.id).all()`.
3. Верни список.

#### Задача 7. Написание эндпоинта `DELETE /collection/{id}`
**Что нужно сделать:** API для удаления марки из коллекции.
**Для чего это нужно:** Для удобства пользователей (если марка добавлена по ошибке).
**Шаги выполнения:**
1. Создай `@router.delete("/collection/{collection_id}")`.
2. Найди запись в БД и удали её.

#### Задача 8. Настройка зависимостей FastAPI
**Что нужно сделать:** Написать функцию `get_current_user`, которая проверяет токен.
**Для чего это нужно:** Чтобы защитить эндпоинты коллекции от неавторизованных пользователей.
**Шаги выполнения:**
1. Открой `backend/app/api/deps.py`.
2. Напиши функцию, которая берет токен из заголовка `Authorization`.
3. Расшифровывает его через `PyJWT` и возвращает пользователя из БД.
4. Используй эту функцию в эндпоинтах коллекции (`Depends(get_current_user)`).

#### Задача 9. Тестирование всех эндпоинтов в Swagger
**Что нужно сделать:** Проверить работу API.
**Для чего это нужно:** Убедиться, что всё работает до передачи Татьяне.
**Шаги выполнения:**
1. Запусти сервер.
2. В Swagger авторизуйся (получи токен).
3. Попробуй загрузить фото на `/recognize` (должен вернуться JSON с координатами).
4. Добавь марку в коллекцию и проверь, что она там появилась.

#### Задача 10. Отправка PR
**Что нужно сделать:** Запушить код и передать работу.

**Для чего это нужно:** Для интеграции.

**Шаги выполнения:**
1. Сделай коммит и пуш в ветку `backend`.
2. Создай Pull Request.
3. Напиши Татьяне: «План №7 готов. Эндпоинты распознавания и коллекции работают».
