#### Задача 4. Написание скрипта для тестирования YOLOv8 на одной картинке
**Что нужно сделать:** Написать первый Python-скрипт, который загружает картинку, прогоняет через YOLO и выводит результат.
**Для чего это нужно:** Это база для всей нашей системы.
**Шаги выполнения:**
1. Создай файл `backend/app/ai/test_detector.py`.
2. Напиши код:
   ```python
   from ultralytics import YOLO
   import cv2

   model = YOLO("yolov8n.pt") 
   image_path = "test_image.jpg" 

   results = model(image_path)

   for result in results:
       boxes = result.boxes
       print(f"Найдено объектов: {len(boxes)}")
       for box in boxes:
           print(f"Координаты: {box.xyxy[0].tolist()}, Класс: {box.cls[0]}")
   ```
3. Положи любую тестовую картинку в папку `backend/app/ai/` и назови её `test_image.jpg`.
4. Запусти скрипт: `python test_detector.py`.

#### Задача 6. Написание функции-обертки `predict(image_path)` для бэкенда
**Что нужно сделать:** Оформить весь код из Задач 4 и 5 в одну удобную функцию, которую сможет вызвать Виктория из своего FastAPI.
**Для чего это нужно:** Виктория не должна знать, как работает YOLO. Она должна просто вызвать функцию и получить готовый список с координатами.
**Шаги выполнения:**
1. Создай файл `backend/app/ai/detector.py`.
2. Напиши функцию:
```python
from ultralytics import YOLO
   
model = YOLO("yolov8n.pt")

def detect_stamps(image_path: str) -> list:
    results = model(image_path)
    detections = []
    for box in results[0].boxes:
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        conf = box.conf[0].item()
        detections.append({
            "bbox": [x1, y1, x2, y2],
            "confidence": conf
        })
    return detections
```
3. В конце файла напиши блок `if __name__ == "__main__":`, чтобы можно было запустить `detector.py` напрямую.
