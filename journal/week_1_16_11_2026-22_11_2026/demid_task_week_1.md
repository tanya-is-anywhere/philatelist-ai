### Ход работы:

#### Задача 1. Установка и настройка DBeaver
**Что нужно сделать:** Скачать и установить программу для визуальной работы с базами данных.
**Для чего это нужно:** Чтобы не писать SQL-запросы в слепую, а видеть таблицы и данные «глазами».
**Шаги выполнения:**
1. Перейди на официальный сайт DBeaver и скачай версию **Community Edition** (она бесплатная).
2. Установи программу на свой компьютер.
3. Запусти DBeaver.

#### Задача 2. Подключение к нашей базе данных в Docker
**Что нужно сделать:** Создать подключение к PostgreSQL, который уже запущен в Docker.
**Для чего это нужно:** База данных уже работает, тебе нужно получить к ней доступ для проверки.
**Шаги выполнения:**
1. Убедись, что у тебя в корне проекта есть файл `.env`. Если его нет — скопируй `.env.example` в `.env`.
2. В DBeaver нажми «Новое подключение» -> выбери **PostgreSQL**.
3. Введи данные:
   * Хост: `localhost`
   * Порт: `5432`
   * База данных: `philatelist_db`
   * Имя пользователя: `philatelist_user`
   * Пароль: возьми значение `DB_PASSWORD` из файла `.env`.
4. Нажми «Test Connection» (если попросит скачать драйвер — соглашайся).
5. Если подключение успешно — нажми «Готово».

#### Задача 3. Сбор данных о 20 марках (Google Таблица)
**Что нужно сделать:** Найти информацию о 20 разных почтовых марках и свести их в таблицу.
**Для чего это нужно:** Виктория создает таблицу марок, но она будет пустой. Тебе нужно подготовить данные, чтобы мы могли их туда загрузить и протестировать.
**Шаги выполнения:**
1. Открой Google Таблицы и создай новый документ.
2. Сделай заголовки: `name` (название марки), `country` (страна), `year` (год выпуска), `price` (примерная цена в рублях).
3. Найди в интернете (или вспомни) 20 реальных марок (например, из серии «СССР», «Российская Империя»).
4. Заполни 20 строк данными.
5. Дай доступ к таблице по ссылке (настройки доступа: «Все, у кого есть ссылка — Читатель»).

#### Задача 4. Экспорт данных в формате CSV
**Что нужно сделать:** Скачать твою Google Таблицу в формате, понятном для Python.
**Для чего это нужно:** Мы будем писать скрипт, который автоматически загрузит этот CSV в базу данных.
**Шаги выполнения:**
1. В Google Таблицах нажми: Файл -> Скачать -> **CSV (текущий лист)**.
2. Переименуй скачанный файл в `seed_stamps.csv`.
3. В проекте (на твоем компьютере) создай папку `backend/tests/fixtures/` (если её нет).
4. Положи файл `seed_stamps.csv` в эту папку.

#### Задача 5. Проверка таблиц, созданных Викторией
**Что нужно сделать:** Проверить, что Виктория успешно создала таблицы в базе данных.
**Для чего это нужно:** Это твоя зона контроля. Если она ошиблась в миграциях, ты должен это заметить первым.
**Шаги выполнения:**
1. Узнай у Виктории (или у Татьяны), когда она выполнит команду `alembic upgrade head`.
2. Зайди в DBeaver, обнови список таблиц (F5).
3. Проверь, что в базе `philatelist_db` появились таблицы `users` и `refresh_sessions`.
4. Открой таблицу `users` и убедись, что там есть колонки: `id`, `email`, `hashed_password`, `is_active`, `created_at`.
5. Сделай скриншот этой структуры.

#### Задача 6. Тестирование API `/register` и `/login` в Swagger
**Что нужно сделать:** Проверить, что API для регистрации и входа работает корректно.
**Для чего это нужно:** Если API падает с ошибкой 500, Татьяна не сможет подключить фронтенд.
**Шаги выполнения:**
1. Убедись, что Татьяна или Виктория слили свои ветки в `develop`, и ты обновил локальную ветку.
2. Запусти бэкенд: `cd backend` -> `uvicorn app.main:app --reload`.
3. Открой в браузере `http://localhost:8000/docs`.
4. Найди метод `POST /api/v1/auth/register`. Нажми «Try it out». Введи тестовый email (например, `test@test.com`) и пароль. Нажми Execute.
5. Проверь, что вернулся статус `200` или `201` (успех).
6. Найди метод `POST /api/v1/auth/login`. Введи те же данные. Проверь, что вернулся `access_token`.
7. Сделай скриншоты обоих запросов.

#### Задача 7. Написание простого `pytest` теста
**Что нужно сделать:** Написать базовый тест, который проверяет, что эндпоинт `/health` отвечает.
**Для чего это нужно:** Это покажет преподавателю, что в проекте есть автоматические тесты.
**Шаги выполнения:**
1. Открой файл `backend/tests/test_auth.py`.
2. Напиши простую функцию:
   ```python
   from fastapi.testclient import TestClient
   from app.main import app

   client = TestClient(app)

   def test_health_check():
       response = client.get("/health")
       assert response.status_code == 200
       assert response.json()["status"] == "ok"
   ```
3. В терминале (в папке `backend`) выполни: `pytest tests/test_auth.py`.
4. Убедись, что тест прошел (зеленая точка).
