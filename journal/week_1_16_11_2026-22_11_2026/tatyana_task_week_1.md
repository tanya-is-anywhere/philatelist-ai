### Ход работы:

#### Задача 1. Настройка базового роутинга и страниц
**Что нужно сделать:** Настроить React Router, чтобы приложение переключалось между экранами.
**Для чего это нужно:** Без этого приложение не будет понимать, какую страницу показывать пользователю.
**Шаги выполнения:**
1. Открой файл `frontend/src/app/router/index.tsx`.
2. Настрой `createBrowserRouter`. Добавь маршруты: `/` (Landing), `/login`, `/register`, `/upload`, `/results`, `/collection`.
3. В качестве заглушек используй простые `<div>Страница...</div>` (пока без реального контента).
4. Открой файл `frontend/src/app/providers/RouterProvider.tsx` и убедись, что `RouterProvider` из React Router подключен.
5. В файле `frontend/src/app/main.tsx` оберни `<App />` в `<RouterProvider>`.

#### Задача 2. Создание UI-кита (базовые компоненты)
**Что нужно сделать:** Написать базовые переиспользуемые компоненты (кнопки, инпуты, спиннеры) с учетом твоей осенней палитры.
**Для чего это нужно:** Чтобы не дублировать код и соблюдать единый стиль.
**Шаги выполнения:**
1. В папке `frontend/src/shared/ui/` создай (если пустые) или заполни файлы: `Button.tsx`, `Input.tsx`, `Spinner.tsx`.
2. В `Button.tsx` пропиши пропсы: `variant` (primary, secondary, ghost), `isLoading` (boolean), `disabled`. Стилизуй через CSS-модули.
3. В `Input.tsx` добавь пропсы для `label` (подпись), `error` (текст ошибки) и возможность показать/скрыть пароль (иконка глаза).
4. В `Spinner.tsx` сделай простую анимацию загрузки (крутящийся круг).
5. В `frontend/src/shared/ui/index.ts` собери экспорты всех компонентов для удобного импорта.

#### Задача 3. Code Review бэкенда
**Что нужно сделать:** Проверить Pull Request от Виктории (настройка Alembic) и убедиться, что база данных готова.
**Для чего это нужно:** Убедиться, что бэкенд работает корректно и готов к сохранению пользователей.
**Шаги выполнения:**
1. Зайди на GitHub, открой PR от Виктории (ветка `backend`). Просмотри изменения в файлах `alembic/env.py` и `models.py`. Если всё корректно — нажми Approve (Одобрить) и Merge (Слить).
2. Переключись локально на `develop` и обнови её (`git pull origin develop`).
3. Запусти бэкенд и выполни команду `alembic upgrade head` (только после того, как код Виктории появился в `develop`).
4. Подключись к БД через DBeaver (или попроси Демида) и проверь, что появились таблицы `users` и `refresh_sessions`.
5. Если таблиц нет или вылезают ошибки — скинь скриншот в наш главный чат (со мной), будем вместе чинить.

#### Задача 4. Верстка страницы LandingPage
**Что нужно сделать:** Сверстать главную страницу (экран приветствия) по твоему макету.
**Для чего это нужно:** Это лицо продукта, первое, что видит пользователь.
**Шаги выполнения:**
1. Открой `frontend/src/pages/landing/ui/LandingPage.tsx`.
2. Размести заголовок, подзаголовок и большую CTA-кнопку («Загрузить фото» или «Начать»).
3. Настрой фон (тот самый «дождь из марок», который мы обсуждали) с помощью CSS.
4. Сделай так, чтобы кнопка вела на страницу `/upload` (через `useNavigate` из React Router). Используй созданный в Задаче 2 компонент `Button`.

#### Задача 5. Верстка страниц авторизации (Login/Register)
**Что нужно сделать:** Сверстать формы входа и регистрации.
**Для чего это нужно:** Пользователи должны иметь возможность создать аккаунт.
**Шаги выполнения:**
1. Открой `frontend/src/pages/auth/ui/LoginPage.tsx` и `RegisterPage.tsx`.
2. Размести форму с полями (Email, Пароль) и кнопкой «Войти» / «Зарегистрироваться».
3. В форму регистрации добавь чекбокс согласия с условиями.
4. Используй созданные в Задаче 2 компоненты `Input` и `Button`.
5. Пока не подключай реальную отправку данных на бэкенд, просто сделай визуальную часть.

#### Задача 6. Настройка Axios и TanStack Query
**Что нужно сделать:** Настроить HTTP-клиент для общения с бэкендом и подготовить почву для запросов.
**Для чего это нужно:** Фронтенд должен уметь отправлять данные на сервер.
**Шаги выполнения:**
1. Открой `frontend/src/shared/api/axiosInstance.ts`.
2. Создай экземпляр Axios с базовым URL: `import.meta.env.VITE_API_URL` (он лежит в `.env.development`).
3. Настрой интерсепторы (пока просто `console.log` для запросов и ответов, чтобы видеть их в консоли).
4. В `frontend/src/app/providers/QueryProvider.tsx` настрой `QueryClient` (укажи `retry: 1`, `refetchOnWindowFocus: false`).
5. Проверь, что приложение запускается без ошибок.

#### Задача 7. Ревью PR и формирование планов на следующую неделю
**Что нужно сделать:** Проверить код ребят на GitHub и распланировать следующий этап.
**Для чего это нужно:** Поддерживать порядок в репозитории и не давать проекту стоять на месте.
**Шаги выполнения:**
1. Зайди на GitHub, проверь вкладку **Pull requests**.
2. Просмотри изменения от остальных участников. Если всё ок — нажми Merge в `develop`.
3. Составь план на следующую неделю: напиши мне в чат «Дай план для Виктории/Игоря/Артёма/Демида на неделю 2».
4. Отправь всем ребятам их планы.

1. Переключись на свою ветку: `git checkout frontend`
2. Убедись, что ты скачала последние изменения из `develop`: `git pull origin develop`
3. Добавь файлы и сделай коммит (команда выше).
4. Отправь изменения на GitHub: `git push origin frontend`
5. Зайди на GitHub, создай Pull Request из ветки `frontend` в `develop`.
6. Так как ты Тимлид, ты можешь сама нажать Approve (одобрить) и Merge (слить) этот PR.
