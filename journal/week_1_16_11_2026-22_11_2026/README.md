# 🗺️ Дорожная карта проекта: Неделя 1 (16.11.2026 - 22.11.2026)
**Цель недели:** Заложить фундамент проекта (Этап 1 и старт Этапа 2). Поднять базу данных, настроить API, создать каркас фронтенда и подготовить данные для ИИ.

---

### 🟢 Старт (День 1-2): Фундамент и Инфраструктура
*Что делаем:* Поднимаем базу данных, настраиваем FastAPI и React, чтобы всё запускалось локально.
*   **Виктория (Backend):** Запускает базу данных в Docker (команда docker-compose up), подключает SQLAlchemy, пишет роут /health и настраивает Alembic.
*   **Татьяна (Frontend):** Инициализирует Vite + React, настраивает базовый роутинг и создает первые страницы (заглушки).
*   **Демид (QA):** Устанавливает DBeaver, подключается к базе данных в Docker (копирует `.env` из `.env.example`). Проверяет, что таблицы создаются корректно.
*   **Игорь (AI/ML):** Настраивает локальное Python-окружение для ИИ, устанавливает `ultralytics` и `PyTorch`.
*   **Артём (AI Data):** Начинает поиск и скачивание исходных изображений для датасета (ориентир: 500 русских + 100 иностранных марок).

### 🟡 Этап 1 (День 3-4): Авторизация и Связка (Старт Этапа 2)
*Что делаем:* Создаем логику входа/регистрации и начинаем связывать фронтенд с бэкендом.
*   **Виктория (Backend):** Пишет `security.py` (JWT), создает эндпоинты `/register` и `/login`, настраивает Pydantic-схемы.
*   **Татьяна (Frontend):** Создает UI-кит (кнопки, инпуты), верстает страницы Логина и Регистрации. Настраивает `axiosInstance.ts`.
*   **Демид (QA):** Собирает данные о 20 марках для будущей базы. Начинает подготовку к тестированию API (изучает Swagger).
*   **Артём (AI Data):** Регистрируется в CVAT, создает проект и начинает загрузку первых 50 фото для разметки.
*   **Игорь (AI/ML):** Тестирует предобученную YOLOv8 на тестовых картинках, пишет скрипт для отрисовки рамок.

### 🟠 Этап 2 (День 5-6): Синхронизация и Тестирование
*Что делаем:* Проверяем, что формы на фронтенде реально отправляют данные на бэкенд и сохраняют пользователей в базу.
*   **Татьяна (Frontend):** Подключает формы регистрации к API Виктории. Настраивает перехватчики Axios для обработки токенов.
*   **Виктория (Backend):** Завершает логику Refresh-токенов. Создает скелет `captcha_service.py` (подготовка к hCaptcha). Помогает Татьяне с интеграцией.
*   **Демид (QA):** Тестирует эндпоинты Виктории через Swagger (после того, как она сольет код в `develop`), создает тестового пользователя.
*   **Артём (AI Data):** Занимается разметкой bounding boxes (рамок) в CVAT.
*   **Игорь (AI/ML):** Начинает писать функцию-обертку `predict(image_path)` для интеграции с бэкендом.

### 🔴 Финал (День 7): Контроль, Слияние и Отчет
*Что делаем:* Собираем всё вместе, проверяем работу, сливаем код в `develop` и фиксируем результат.
*   **Все участники:** Делают Pull Request (PR) со своими ветками (`backend`, `frontend`, `ai`) в `develop`.
*   **Татьяна (TeamLead):** Проверяет PR, делает Code Review, сливает ветки. Запускает проект целиком. Проверяет создание таблиц в БД через DBeaver.
*   **Демид (QA):** Проводит финальное тестирование API и проверяет, что база данных наполняется.
*   **Все участники:** Заполняют галочки в своих `.md` файлах задач в папке `journal`.

---

### 🏆 Результат к концу недели (Definition of Done):
1. **Инфраструктура:** Проект запускается одной командой. Docker, FastAPI и React работают без ошибок.
2. **База данных:** В PostgreSQL созданы таблицы `users` и `refresh_sessions`.
3. **Бэкенд:** Работают эндпоинты регистрации и входа (проверено в Swagger).
4. **Фронтенд:** Сверстаны страницы LandingPage, Login и Register. Кнопки и инпуты готовы к использованию.
5. **AI-данные:** Начата работа над датасетом (ориентир: 500 русских + 100 иностранных марок). Первые фото загружены в CVAT.
