## 2. Как мы ставим задачи
Каждую неделю каждый участник получает файл `.md` со своими задачами в папке `journal/week_*`.
Формат файла: `[Имя]_task_week_[Номер].md`.

## 3. Процесс работы (Workflow)
1. Получаешь задачу на неделю.
2. Отмечаешь выполненные пункты, ставя `x` в квадратные скобки: `- [x] Задача 1`.
3. Выполняешь задачи, пушишь код в свою ветку.
4. В пятницу (или по готовности) создаешь Pull Request (PR) в `develop`.
5. Пишешь Тимлиду: «План [Номер] выполнен. Прошу проверить PR».

## 4. Git Flow и ветки
- `main` — стабильный код (защищена).
- `develop` — ветка для сборки (защищена).
- Ветки для работы: `frontend`, `backend`, `ai`, `ai-data`.
- **Временные ветки:** если нужно внести срочные правки, создавай фича-ветки (например, `feature/backend-auth`).

## 5. Правила коммитов

Мы используем стандарт **Conventional Commits**. Это помогает нам легко читать историю изменений и понимать, кто и что сделал, не заглядывая в код.

**Формат:** `тип(область): краткое описание`

**Основные типы:**
* `feat` — новый функционал (добавление эндпоинта, кнопки, модели).
* `fix` — исправление ошибки.
* `docs` — изменения в документации (наш журнал, README).
* `refactor` — переписывание кода без изменения его поведения (оптимизация).
* `chore` — рутинные задачи (обновление зависимостей, настройка конфигов).
* `test` — добавление или изменение тестов.

**Области (scope):**
* `backend` — серверная часть (Python, FastAPI, базы данных).
* `frontend` — клиентская часть (React, верстка, стили).
* `ai` — код нейросетей, инференс, логика поиска по векторам.
* `data` — работа с датасетами (поиск фото, разметка, конвертация). *(Используется в основном Артёмом).*
* `journal` — файлы с задачами в папке `journal`.

**Примеры для каждой роли:**

* **Тимлид (Татьяна):**
  * `docs(journal): добавлены задачи на неделю 1 для всех участников`
  * `chore(project): обновлена конфигурация docker-compose`


* **Frontend (Татьяна):**
  * `feat(frontend): добавлен макет формы входа`
  * `fix(frontend): исправлен цвет кнопки при наведении`
  * `style(frontend): обновлена осенняя цветовая палитра`

* **Backend (Виктория):**
  * `feat(backend): добавлена ротация refresh-токенов`
  * `fix(backend): исправлен конфликт миграций alembic`
  * `refactor(backend): оптимизированы запросы к базе данных`

* **QA & База данных (Демид):**
  * `test(backend): добавлены pytest-тесты для эндпоинтов авторизации`
  * `chore(backend): добавлено 50 марок в тестовую базу данных`

* **AI/ML (Игорь):**
  * `feat(ai): интегрирована модель YOLOv8 для детекции`
  * `feat(ai): добавлено извлечение эмбеддингов через DINOv2`
  * `fix(ai): исправлена проблема с масштабированием bounding boxes`
  * `refactor(ai): оптимизировано время загрузки модели`

* **AI Data (Артём):**
  * `data(ai): добавлена первая партия из 250 изображений для YOLO`
  * `data(ai): экспортированы аннотации из CVAT в формат YOLO`
  * `docs(ai): описание структуры датасета в readme`
